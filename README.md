# VIN Decoder

SPA для розшифровки автомобільних VIN-кодів через відкрите API агенції NHTSA.

**[Відкрити застосунок →](https://NacnudONE.github.io/vin-decoder/)**

---

## Функціонал

- **Головна сторінка** `/` — форма введення VIN з валідацією, список 3 останніх запитів, таблиця результатів декодування
- **Сторінка змінних** `/variables` — повний список змінних NHTSA API з пошуком за назвою
- **Деталі змінної** `/variables/:id` — назва, тип даних, група та опис конкретної змінної

### Особливості

- Валідація VIN: не порожнє, max 17 символів, тільки латиниця та цифри (без I, O, Q — стандарт ISO 3779)
- Відображення помилок валідації та повідомлень від API
- Збереження 3 останніх VIN-кодів у `localStorage` — клік на кнопці повторює декодування
- Адаптивна верстка від 420 до 1440 px
- Семантична HTML-структура (`header`, `nav`, `main`, `section`, `table`, `footer`)
- Підтримка світлої та темної теми (через `prefers-color-scheme`)

## Локальний запуск

**Вимоги:** Node.js 18+

```bash
# Клонувати репозиторій
git clone https://github.com/NacnudONE/vin-decoder.git
cd vin-decoder

# Встановити залежності
npm install

# Запустити dev-сервер
npm run dev
```

Застосунок буде доступний за адресою `http://localhost:5173/vin-decoder/`
